# ADR 0016: Out of scope: DRM video and AirPlay 2 multi-room audio

Status: accepted (2026-10-18)

## Decision

- FairPlay-protected video (Apple TV+, Netflix casting) is not supported: it needs
  Apple's licence.
- AirPlay 2 buffered multi-room audio (PTP, sync with HomePods) is not supported:
  UxPlay doesn't implement it.
- HomeKit integration is not planned.
